### Bash

- Essa nova versão não usa bibliotecas externas; 
- É apenas html, css e js vanilla;
- É possível executar o arquivo index.html direto no navegador;
- A criação de arquivos/pastas não permanece após atualizar a página.

### Comandos disponíveis 

```    
    ls                     Lista os arquivos do diretório atual
    pwd                    Exibe o caminho do diretório atual
    cd <dir>               Navega entre diretórios
    cat <arquivo>          Exibe o conteúdo de um arquivo
    echo <texto> > <arq>   Sobrescreve/cria o conteúdo de um arquivo
    mkdir <nome>           Cria um novo diretório
    touch <nome>           Cria um novo arquivo vazio
    rm [-r] <alvo>         Remove arquivos ou diretórios (-r para pastas)
    clear                  Limpa a tela
    date                   Exibe a data e hora atual
```
